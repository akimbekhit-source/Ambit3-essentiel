# Ambit3 Essentiel

Adaptation Android de [Sommet](https://github.com/skinnie/sommet) pour Suunto Ambit3.

Cette branche contient les scripts et les extensions natives de la version 0.2.73. Les [notes de construction](ambit3-build/README.fr.md) décrivent les dépendances nécessaires. La licence GPLv3 et les crédits du projet Sommet sont inclus.
