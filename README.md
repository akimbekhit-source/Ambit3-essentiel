# Ambit3 Essentiel

Adaptation Android de [Sommet](https://github.com/skinnie/sommet) pour Suunto Ambit3.

## Version 0.2.79

Le [patch cumulatif](patches/ambit3-essentiel-0.2.73-to-0.2.79.patch) s’applique à l’archive des sources Ambit3 Essentiel 0.2.73 avec `git apply`. Il regroupe les courbes de séance, l’historique cardio jour et nuit, le suivi de nuit programmé et la nouvelle tentative de connexion Bluetooth.

Les [notes de construction](ambit3-build/README.fr.md) décrivent la base et les dépendances du projet. La licence GPLv3 et les crédits de Sommet sont inclus.
